# Análisis de Sentimientos - Restaurantes El Salvador

Aplicación en Streamlit para analizar el sentimiento de comentarios de clientes de restaurantes, con traducción automática y detección de idioma.

## Requisitos

- Python 3.9+

## Instalación

```bash
pip install -r requirements.txt
```

## Uso

```bash
streamlit run AnalisisSentimientosRestaurante_App.py
```

## Funcionalidades

- Traducción automática y detección de idioma de comentarios
- Análisis de sentimiento (positivo/negativo/neutral) con TextBlob
- Historial acumulado de comentarios analizados
- Gráficas de distribución de sentimientos y palabras frecuentes
- Filtrado y exportación de reportes en CSV
- Vista de detalle técnico por comentario
